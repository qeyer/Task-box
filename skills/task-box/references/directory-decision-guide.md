# 目录选择

新建任务采用以下一级名称，按需创建；用户指定结构优先。旧目录不自动改名或移动。

| 名称 | 用途 |
|---|---|
| 素材 | 原始文档、参考资料、图片、音视频、原始数据、需求附件 |
| 工作文件 | 草稿、脚本、分析结果、处理数据、设计工程、测试记录、临时文件 |
| 预览 | 给用户审核的样张、截图、试看片、试读和试用版本 |
| 成品 | 正式交付的文档、图片、表格、音视频、演示稿、软件包 |
| 归档 | 需要保留且与当前版本分开的历史交付 |

只建实际需要的目录。简单任务可以仅有成品目录；根目录默认不散放文件。
同用途保持同名：“资料”归入素材，“最终成品”“交付物”“最终交付”统一叫成品。
领域差异放在二级目录，文件少时不继续分层：
- 文案、研究、会议：工作文件/草稿、工作文件/视频拆解。
- 音视频：素材/录音、工作文件/字幕、工作文件/剪辑工程。
- 设计与演示：素材/视觉参考、工作文件/设计稿。
- 数据：素材/原始数据、工作文件/处理数据、工作文件/脚本。
- 软件仓库：源码、测试和配置保持原结构，上述目录只用于任务资料和导出物。

内部测试截图归工作文件；给用户送审的截图归预览。可编辑工程属于交付要求时，也放入成品。
历史文件只在已授权范围内归档，不自动清理素材或旧成品。

一次性简单任务省略记录；续做、多轮修改或交接需要时，在工作文件/任务记录.md 记录当前成品和待办。
链接相对于记录所在目录，例如 ../成品/报告.docx。旧任务已有任务说明.md 时继续复用，不另建一份。
